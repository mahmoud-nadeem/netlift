# 5. Methods — Baselines and meta-learners

NetLift ranks eligible records by the estimated change in conversion probability caused by treatment assignment. Let $X$ be the pre-treatment features, $T$ the randomized assignment, and $Y$ the observed conversion outcome. The estimand is the intention-to-treat (ITT) contrast $\tau(x)=\mu_1(x)-\mu_0(x)$, where $\mu_t(x)=\mathbb{E}[Y\mid X=x,T=t]$. For Criteo, treatment assignment and observed ad exposure are distinct. The feature contract excludes exposure, treatment and outcomes from the input feature table. The S-learner receives assignment internally as a model input so it can score both arms for the same record. ## 5.1 Targeting baselines

| Baseline | How it selects records | Role in the comparison |
| --- | --- | --- |
| Random | Assigns seeded uniform scores and takes the highest-ranked records up to the contact budget. | Measures what budget-matched targeting achieves without using customer features. |
| Blanket | Selects every eligible record. Its effect is the treated-minus-control conversion-rate difference over the full population, and its cost is the population size times the per-contact cost. | Provides a full-coverage reference. Show its actual cost when it exceeds the comparison budget. |
| Response model | Fits a binary LightGBM classifier on treated training rows and ranks all validation rows by $\widehat{\mu}_1(x)$. | Represents a conventional response-targeting policy. Its scores estimate conversion under treatment. |

T38 ran the initial baselines on Hillstrom. The tuned response baseline for the primary K1 comparison uses Criteo conversion. Its hyperparameters are selected by out-of-fold log loss on treated training rows. The selected model is refitted on all treated rows in the full training split and scores the full validation split. K1 uses aligned validation records and the same contact budget for the response policy and the uplift policy. ## 5.2 S-, T-, and X-learners

| Learner | How NetLift computes the uplift score |
| --- | --- |
| S-learner | Fits one LightGBM outcome classifier to both arms with assignment as an extra input. Scores the same features twice, with assignment set to treatment and control, then subtracts the control probability from the treated probability. |
| T-learner | Fits a separate LightGBM outcome classifier in each arm. Scores each record with both classifiers and subtracts the predicted control probability from the predicted treated probability. |
| X-learner | Starts with the T-learner's outcome models. For treated rows, subtracts the predicted control outcome from the observed outcome. For control rows, subtracts the observed outcome from the predicted treated outcome. Fits a LightGBM regressor to these imputed effects in each arm. The final score weights the control-arm effect prediction by the treated share in training and the treated-arm effect prediction by the remaining share. |

For the preliminary T56 comparison, we fitted the learners with fixed LightGBM settings on Criteo conversion training data and scored the same validation rows for all learners. The runs save scores keyed by row ID. Paired bootstrap intervals use the same resampled rows across learners, with resampling performed separately within each treatment arm. The test split stayed locked. ## 5.3 Class transformation and treatment imbalance

Class transformation fits a single classifier on the label $Z=\mathbf{1}\{T=Y\}$. When each arm has assignment probability one-half conditional on the features, $2P(Z=1\mid X=x)-1$ recovers the conditional uplift. Criteo has unequal assignment shares, so the unweighted transformed probability gives unequal weight to the two arm response rates. Applying the balanced-arm formula to that probability can introduce a systematic offset. NetLift balances the training weights by giving each arm equal total weight, then applies the same transformation to the weighted classifier's probabilities. [Class-transformation implementation](https://github.com/mahmoud-nadeem/netlift/blob/0709392815b8fd7d75d1576111afb3180b5897c0/src/netlift/models/meta_learners.py#L63)

The Criteo conversion validation demonstration shows a large negative average score for the unweighted classifier and a weighted average near zero. The observed treated-minus-control conversion-rate difference was **+0.1153 percentage points** (within-arm bootstrap 95% CI **[+0.0999, +0.1308]**). The weighting removed the large negative shift in average predictions. The weighted average still fell below the observed difference, and calibration requires its own assessment. The demonstration also displays descriptive Qini curves.
