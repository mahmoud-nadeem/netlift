## Method and pre-registered thresholds

- SMD = (mean_treated - mean_control) / sqrt((var_treated + var_control) / 2). Categorical covariates are one-hot encoded, one SMD per level. Flag if |SMD| > 0.1 (spec: conventional 0.1, set in config).
- Treatment AUC: 5-fold out-of-fold predictions from a gradient-boosted classifier using covariates only. Rows with identical covariate profiles are kept in the same fold (StratifiedGroupKFold) so duplicated profiles cannot inflate the AUC. FAIL if the lower bound of the 95% bootstrap CI exceeds 0.55 (team choice: the spec says only 'materially above 0.5').
- Overlap: out-of-fold propensity scores must lie inside [0.01, 0.99] for at least 99% of rows.
- Excluded: outcomes (visit, conversion, spend) and Criteo `exposure` (post-treatment, zero for every control row by construction, per the spec).
- Seed 42; AUC computed on at most 500,000 random rows per comparison.
